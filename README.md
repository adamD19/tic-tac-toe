# Tic Tac Toe (React + Vite) — GitHub Pages

A simple 2-player Tic Tac Toe game built with **React** (via **Vite**) and deployed to **GitHub Pages**.

Features:
- 2-player local play (X goes first, then O)
- Win + draw detection (winning line highlights)
- Reset button
- **Fun Mode** toggle:
  - Switches the UI to a more colorful theme
  - Changes displayed symbols:
    - **X → red `*`**
    - **O → blue `@`**
- Layout is centered and the theme background fills the entire window

---

## Requirements

- Node.js (recommended: LTS)
- npm

Check versions:
```bash
node -v
npm -v
```

## Install & Run Locally
npm install
npm run dev
